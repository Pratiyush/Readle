# Readle review — 2026-11-08

Reviewer: Claude (session started from the German hub). Scope: the React/Vite PWA on branch
`ccr-7aeb8ea1-63oetl` (single commit `e0cc25f`, 2026-10-17), its content pipeline, CI, and the route
to Android + iOS. Nothing was pushed: 12 local commits on the current branch (the 11 listed at the end, plus this review).

## Bottom line

The reader is a solid, small codebase (about 1,600 lines of TS/TSX, 170 KB JS / 55 KB gzipped) and
the German is good. Four high-severity defects broke its main promises: offline gave a blank page,
audio kept playing after leaving a story, the dictionary glossed names by a random tail
("Deutschland" → *Land* 24 times, "Terrasse" → *Rasse*), and CI had never run. All four are fixed
locally, along with five medium issues. Still open: the mobile path, the name, thumbnails, icons,
safe areas, and native text-to-speech on Android.

## CI

**Proposal: rename the default branch to `main`** (GitHub → Settings → Branches → rename; GitHub
redirects the old name and retargets open PRs). It matches the README, the convention, and how cloud
sessions open `ccr-*` branches as PRs into the default branch.

Either way, the workflow no longer depends on the name. Commit `3b49f4c` runs typecheck, test and
build on **every push and PR**. Deploying to GitHub Pages is **opt-in**: it runs only for pushes to
the default branch when the repository variable `DEPLOY_PAGES` is `true`, so CI stays green and
nothing goes public until you decide whether the web version stays live. `actionlint` passes.

Owner steps: approve the push, rename the branch, and decide on Pages (an existing question).

for all four German apps. The cost: the web PWA becomes a second codebase, so freeze it as-is or
retire it. Choose (a) instead only if a live, ad-free web version is worth more to you than those
three things.

## Name

"Readle Deutsch" reuses the reference app's brand (Readle, `com.langster.languages`). Three original
names, none of which turned up as an existing app in a quick web search on 2026-11-08 (not a
trademark search; check DPMA/EUIPO and both stores before committing):

1. **Erzählbar**: "tellable", with a wink at *Bar* (a place you drop into for a story). Fits the
   story-first positioning and sits apart from Lernle, Tobo and WordBit.
2. **Satzweise**: "sentence by sentence", the app's core mechanic (tap, translate and listen per
   sentence). Closest existing name found: "Satzly" (Play), which is different enough.
3. **Leselicht**: "reading light". Warm and evening-reading in tone, with an easy icon. Only
   flashlight apps came up for the term.

Avoid any "-le" ending (Readle, Lernle, Wordle echo) to keep the four apps distinct for 4.3.
